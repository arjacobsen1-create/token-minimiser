Token Minimiser

Built by Anahita Jacobsen

Paste a prompt. The minimiser shrinks it, then does the part most tools skip: it predicts the reply, because a tiny prompt can trigger a huge, expensive answer. It minimises the total, input plus predicted output, and reports the saving as a range, framed by how you pay.

Open the dashboard →

1 · Paste your prompt, exactly as you would send it.
2 · Choose control: Gentle, Balanced or Aggressive, how hard the reply gets capped.
3 · Copy the minimised prompt and send that instead. Same job, smaller bill.
