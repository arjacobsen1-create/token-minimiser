Token Minimiser

Built by Anahita Jacobsen · Live demo

Paste a prompt. The minimiser shrinks it, then does the part most tools skip: it predicts the reply, because a tiny prompt can trigger a huge, expensive answer. It minimises the total, input plus predicted output, and reports the saving as a range, framed by how you pay. Runs entirely in your browser, on the same engine as the code in this repo (src/minimiser-core.js).
